# polymarket-maker

PAPER-ONLY test kit for the open-source [warproxxx/poly-maker](https://github.com/warproxxx/poly-maker)
Polymarket market-making bot: our scale fixes, a fill simulator with markout logging, a dashboard,
and a one-shot Oracle Cloud (Always Free) setup.

Start here:
- Windows PC, no card, low resources: [oracle/WINDOWS_SETUP.md](oracle/WINDOWS_SETUP.md)
- Oracle Cloud free server: [oracle/ORACLE_SETUP.md](oracle/ORACLE_SETUP.md)

No private keys, wallets or `.env` files live in this repo.
